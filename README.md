## The entry

`main.py` is a deterministic, standard-library-only program. It writes one
funny single-line rejected Olympic sport to `/output/entry.txt`:

> Synchronized sighing: teams exhale in perfect unison while judges deduct
> points for anyone who actually feels better.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
